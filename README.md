# 丁香皮肤 · dsh-lilac-skin

DeepSeek Harness 网页界面的紫色皮肤。用紫罗兰与丁香紫色系给整个 Web UI 换色：淡紫表面、深紫主按钮，用户气泡是很淡的丁香色，滚动条与轮次导航条也跟着走。

浅色与深色的配色分工：

| 位置 | 浅色 | 深色 |
| --- | --- | --- |
| 表面 / 侧边栏 | 淡紫 `#FBF8FE` / `#F7F1FC` | 近黑紫 `#16121C` / `#120F18` |
| 主按钮 / 链接 / 焦点环 | 深紫 `#7400C2` | 淡丁香 `#E8BFFF` · 链接 `#C99BFF` |
| 用户消息气泡 | `#F0E4FF`，丁香紫描边 | `#463A57`，亮紫描边 |
| 轮次导航条（当前 / 悬停） | `#C69DE4` / `#BC83DE` | `#E8BFFF` / `#D4A9F0` |
| 滚动条滑块（默认 / 悬停） | `#C3ABDE` / `#A181C6` | `#4A3F5A` / `#5E5170` |

## 它怎么工作

皮肤不改主题注册表，而是通过 `ctx.theme.overrideTokens` 在**当前主题之上**叠一层 token：101 个 alias/specific token，每个都给出浅色与深色两个值，跟随你在「外观」里选的浅色 / 深色 / 跟随系统。没被覆盖的 token 保持主题原值，图层由插件上下文持有，停用即复原，不需要刷新。

另外有一条很小的样式：轮次导航条上的「当前轮次」原本用正文色画，无法只改这一条，因此用一条结构选择器把它改成紫色（停用插件时一并移除）。

## 安装

任选一种：

1. **从 GitHub 装**（本机需已安装 Git）：**插件** 页面 → 添加插件 → 填 `github:Eric782155/dsh-lilac-skin`
2. **从本地目录装**：把本仓库放到本地，添加插件时选这个目录（开发时最方便，改完文件停用再启用即可重载）
3. **从 npm 装**（如果之后发布到 npm）：填包名 `dsh-lilac-skin`

装上后会作为 bundle 进入当前 profile；刷新页面就能看到配色。

## 关闭

**插件** 页面停用「丁香皮肤」，配色立即恢复原样，无需重启。

## 刻意保留原配色的部分

成功 / 警告 / 错误状态色、语法高亮、文件差异、JSON 树、文档预览表面都沿用主题原值——这些是语义色，换掉会让状态难以一眼辨认。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `client.js` | 全部配色：token 表 + 轮次导航条那一条样式 |
| `index.js` | Host 半区（空实现，bundle 需要一个可加载的入口） |
| `cordis.patch.yml` | 插入 Loader 行 `lilac-skin` |
| `locale/*.json` | 中英文标题与简介 |
| `icon.svg` | 插件图标 |
| `docs/` | 详情页配图与说明 |
